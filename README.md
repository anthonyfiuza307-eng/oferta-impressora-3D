# Coleção Sacra 3D — Landing Page de Alta Conversão

Landing page responsiva de alta performance e conversão desenvolvida para a venda da **Coleção Sacra 3D** (+500 modelos STL católicos prontos para impressão 3D).

---

## 🚀 Tecnologias

- **HTML5 Semântico**: Estrutura otimizada para SEO, acessibilidade e carregamento rápido.
- **CSS3 Moderno**: Design system sob medida, dark mode com detalhes dourados sacros, glassmorphism e microinterações responsivas.
- **Vanilla JavaScript**:
  - Cronômetro de urgência regressivo sincronizado com o Horário de Brasília (GMT-3).
  - FAQ dinâmico em acordeão.
  - Barra flutuante mobile de CTA inteligente.
  - Modais de upsell inteligente e retenção por inatividade.
  - Meta Pixel integrado para rastreamento de anúncios e tráfego.

## 🌐 Deploy na Vercel

O projeto está configurado para deploy estático com zero configurações extras necessárias:

1. Suba este repositório no seu **GitHub**.
2. Acesse [vercel.com](https://vercel.com) e clique em **Add New Project**.
3. Importe o repositório do GitHub.
4. Mantenha as configurações padrão (Framework Preset: **Other** / Root Directory: `./`).
5. Clique em **Deploy**.
